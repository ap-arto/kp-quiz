# KP Quiz

Квіз для підготовки до співбесіди на Карту поляка. Вимоги до MVP — у [SPEC.md](SPEC.md).

Наразі налаштовано стартовий React + TypeScript проєкт на Vite. Логіку квізу та навчальний контент буде додано окремо.

## Локальний запуск

Потрібні Node.js 22.12+ та npm. Для nvm: `nvm use`.

```sh
npm ci
npm run dev
```

Відкрити адресу, яку виведе Vite (типово http://localhost:5173/kp-quiz/).

## Команди

- `npm run dev` — сервер розробки.
- `npm run build` — перевірка TypeScript і production-збірка в `dist/`.
- `npm run lint` — перевірка коду через Oxlint.
- `npm run preview` — локальний перегляд готової збірки.

Залежності зафіксовано в `package-lock.json`; для відтворюваного встановлення використовуйте `npm ci`.

## GitHub Pages

У Vite задано базовий шлях `/kp-quiz/` для майбутньої публікації в підкаталозі репозиторію. Деплой ще не налаштовано.
