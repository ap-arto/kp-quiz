# KP Quiz

Мобільний квіз для підготовки до співбесіди на Карту поляка. React + TypeScript + Vite, без бекенду та акаунтів. Вимоги — у [SPEC.md](SPEC.md).

## Що працює

- Шість тем і 44 питання польською з матеріалів `kp-data`.
- Швидкий квіз: до 10 питань; повний: усі питання вибраної теми без повторів.
- Спочатку нові питання, потім питання за зростанням частки правильних відповідей; випадковий порядок при однакових показниках.
- Чотири перемішані відповіді, одноразове зарахування, правильна відповідь і факт після вибору, ручний перехід далі.
- Підсумок поточного проходження та розбір лише помилок.
- Український і польський інтерфейс. Тексти питань залишаються польською.
- Статистика кожної відповіді та мова зберігаються одразу в `localStorage` (`kp-quiz:v1`). Перезавантаження починає нове проходження; статистика залишається. Якщо браузер блокує збереження, застосунок показує повідомлення і продовжує працювати в пам’яті.

## Локальний запуск

Потрібні Node.js 22.12+ та npm. Для nvm: `nvm use`.

```sh
npm ci
npm run dev
```

Адреса: `http://localhost:5173/kp-quiz/`. Залежності зафіксовано у `package-lock.json`.

```sh
npm test               # 7 перевірок даних, вибору питань, reducer, статистики та storage
npm run lint           # Oxlint
npm run build          # TypeScript + production-збірка в dist/
npx playwright install chromium
npm run test:e2e        # 8 браузерних тестів: Chromium desktop та mobile
npm run preview        # перегляд production-збірки
```

Браузерні тести перевіряють повне проходження, розбір помилок, збереження після кожної відповіді, перезавантаження, перемикання мови, недоступний storage, клавіатуру й ширину 320 px. Mobile-проєкт використовує Chromium з розміром та touch-параметрами iPhone; це не перевірка Safari на фізичному пристрої.

## Контент

`src/data/questions.json` містить категорії, питання, відповіді, правильний `id`, факт та `source` — файл і номер розділу у `kp-data/data/questions/`.

Це початкова добірка з шести розділів джерела, а не повний імпорт. Правильні відповіді й факти адаптовано з цих матеріалів; неправильні варіанти створено для формату multiple choice. Поточних політиків, змінних числових показників і неоднозначних питань у добірці немає. Джерельний репозиторій не змінювався.

Для розширення додайте питання до JSON, залишайте стабільні `id` незмінними при редактурі та вказуйте джерело. `npm test` перевіряє унікальність, чотири різні варіанти, правильний `id`, категорії та факти. При свідомій зміні розміру набору оновіть контрольну кількість у тесті.

## GitHub Pages

Публікація наразі заблокована тарифом GitHub: API створення Pages для приватного `ap-arto/kp-quiz` повернув HTTP 422 — `Your current plan does not support GitHub Pages for this repository.` Сайт ще не опубліковано; приватність репозиторію не змінено. Потрібен тариф із Pages для приватних репозиторіїв або окреме рішення про інший спосіб публікації.

Збірка використовує базовий шлях `/kp-quiz/`; окремий роутер не потрібен. Workflow `.github/workflows/ci.yml` перевіряє код, запускає браузерні тести та готує Pages artifact при push у `main`, у pull request і при ручному запуску.

Деплой виконується лише якщо repository variable `PAGES_ENABLED` дорівнює `true`. Перед увімкненням потрібно налаштувати **Settings → Pages → Source: GitHub Actions**. Для приватного репозиторію доступність Pages залежить від тарифу GitHub. Workflow не змінює приватність репозиторію.

Після налаштування Pages та змінної наступний push у `main` або ручний запуск **Check and deploy** опублікує сайт за адресою `https://ap-arto.github.io/kp-quiz/`.
