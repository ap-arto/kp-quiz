# Контент категорії «Відомі поляки»

Актуальна добірка складається з 30 питань польською, наданих користувачем. Усі питання мають чотири варіанти, одну правильну відповідь і короткий пояснювальний факт. Поділ вихідного матеріалу на підкатегорії не зберігається: у застосунку всі питання належать до категорії `people`.

## Теми

| Тема | Питань |
| --- | ---: |
| Нобелівські лауреати | 8 |
| Література | 3 |
| Музика | 3 |
| Наука | 4 |
| Кіно | 6 |
| Спорт | 4 |
| Релігія та покровителі | 2 |
| **Разом** | **30** |

Попередній файл даних із 132 питаннями, серед яких було 94 питання про відомих поляків, збережено як `src/data/questions-with-94-people.archived.json`. Застосунок його не імпортує.

Документацію старої розширеної добірки збережено у `docs/people-content-94-archived.md`.

## Перевірки

`npm test` перевіряє структуру всього активного набору, унікальність ID і формулювань, чотири різні варіанти відповіді, коректний ID відповіді, 30 питань категорії та послідовні позначки джерела.
